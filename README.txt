Nový web CARC – návrhy designu (statická verze)

Obsah:
  index.html          přehled šesti variant (otevřít v prohlížeči)
  varianty/A–F.html   úvodní stránky variant
  varianty/img/       fotografie
  img/                náhledy a logo
  FORMULAR-text.md    text formuláře pro MS Forms / Google Forms

Zveřejnění:
  Celou složku nahrajte beze změny struktury na libovolný webový server
  (intranet, SharePoint jako web, GitHub Pages apod.). Nic dalšího není potřeba.
  Písma se načítají z Google Fonts – bez internetu se zobrazí náhradní písmo.

Před zveřejněním doplňte v index.html:
  [ODKAZ NA FORMULÁŘ]  – odkaz na formulář s hlasováním
  [DATUM]              – termín ukončení hlasování

Poznámka: SharePoint knihovna dokumentů HTML soubory často jen stáhne místo
zobrazení – pak použijte jiný webový prostor nebo pošlete ZIP k otevření lokálně.
